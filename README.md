# portfolio-tech-pm-analytics1# 📊 Projeto: Gestão Ágil e Analytics em Infraestrutura de TI

Este projeto pessoal simula o planejamento e o monitoramento executivo da migração de uma infraestrutura legada de e-commerce para um ambiente moderno em nuvem (baseado em servidores Linux).

## 🚀 Tecnologias e Ferramentas Utilizadas
* **Trello:** Planejamento ágil utilizando a metodologia Kanban para o gerenciamento do fluxo de tarefas (Backlog até o Concluído).
* **Power BI Desktop:** Construção de um Dashboard Executivo para análise de dados e tomada de decisão estratégica corporativa.
* **Markdown / GitHub:** Versionamento do projeto e documentação técnica das entregas.

## 📋 Escopo e Fluxo de Gestão (Trello)
O projeto foi estruturado em sprints com foco em governança, segurança da informação (mitigação de riscos em senhas de servidores Linux) e engenharia de dados.
